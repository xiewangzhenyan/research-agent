# 原生知识库核心能力迁移清单

本项目的主线是把 WeKnora 的核心知识库能力在现有项目内落地，不依赖其运行时接口。课题组/科研只是使用场景；文献课程、专业术语扩充和阅读路径不再驱动底层开发优先级。先前“科研入门路径”路线已被本清单替代。

## 对照依据与边界

本次实际读取 Tencent/WeKnora 的公开源码，固定版本为 `3ab6d3940d1564f4db69d011941041e366370de7`（提交时间 2026-09-09 10:17:10 UTC）。以下是已阅读文件的能力对照，不是完整产品审计，也不表示本项目与其实现完全等价。

- [知识库、分块与 FAQ 配置](https://github.com/Tencent/WeKnora/blob/3ab6d3940d1564f4db69d011941041e366370de7/internal/types/knowledgebase.go)：片段长度、重叠、分隔符、解析器、父子块及策略配置。
- [分块策略](https://github.com/Tencent/WeKnora/blob/3ab6d3940d1564f4db69d011941041e366370de7/internal/infrastructure/chunker/strategy.go)：策略选择、回退、分块验证及预览诊断入口。
- [检索配置](https://github.com/Tencent/WeKnora/blob/3ab6d3940d1564f4db69d011941041e366370de7/internal/types/retrieval_config.go)：向量/关键词阈值、检索深度、重排模型与阈值、RRF 权重。
- [重排流程](https://github.com/Tencent/WeKnora/blob/3ab6d3940d1564f4db69d011941041e366370de7/internal/application/service/chat_pipeline/rerank.go)：模型重排流程。
- [上下文扩展](https://github.com/Tencent/WeKnora/blob/3ab6d3940d1564f4db69d011941041e366370de7/internal/application/service/chat_pipeline/merge_expand.go)：回答前对短片段取相邻块扩展上下文。

实现采用当前 Python/FastAPI 项目的本地服务和数据结构，并非直接复制 Go 代码。本地中文向量模型保持现有配置，回答生成仍使用管理员配置的语言模型。

## 能力差距

| 能力 | 当前状态 | 下一步 |
|---|---|---|
| 文件接入、持久化任务、状态、失败重试和删除 | 基础与逐文件批量结果已实现 | 更多导入类型、任务管理待补 |
| PDF/Word/文本/CSV 解析 | 基础已实现 | OCR、更多格式和可选解析器仍缺失 |
| 分块长度、重叠设置及入库前预览 | 已实现基础配置、真实预览与确认参数固定 | 分隔符、策略与父子块仍缺失 |
| 本地向量生成 | 已实现固定中文模型 | 模型管理、变更后的重建流程待补 |
| 关键词＋向量混合检索 | 已实现模式、阈值、权重、深度配置及真实诊断 | 已补本地重排与回答前邻块扩展；专用索引后端待补 |
| 问题改写 | 已有短追问改写 | 与上游更完整的查询理解流程不等价 |
| 重排 | 已实现可选本地中文模型与排名诊断 | 扩大真实资料评测，优化吞吐 |
| 回答前的上下文扩展/合并 | 已实现带预算、代次及范围约束的邻块扩展 | 父子块仍缺失；跨页保留独立引用 |
| 原文引用、页码、快照 | 已实现 | 随后续扩展验证跨块位置与引用完整性 |
| FAQ/手动知识/网页导入 | 已实现手动知识与 FAQ 的在线编辑、重新索引和引用 | 相似问法、批量 FAQ、网页导入仍缺失 |
| 账号隔离 | 已实现 | 不等于租户/组织共享权限；共享需独立设计 |

特别说明：引用面板里的“展开前后文”是阅读功能，不能算作回答前的上下文扩展；增加专业术语也不能算作模型重排；现有向量存储是有界 SQL 数组检索，不等于专用向量索引。

## 接下来的开发顺序

1. **知识库处理配置**：已实现长度与重叠配置、实际配置快照、重新处理提示及入库前分块预览；策略与父子块待补。
2. **检索链路配置与诊断**：已实现账号级配置与临时测试覆盖，统一模式、深度、阈值和 RRF 权重，显示真实候选/排名信息；聊天复用相同配置并保存当次诊断。
3. **本地重排与回答前上下文扩展**：已实现可选重排和预算内邻块扩展，验证合成通用资料排序、跨页独立引用、账号隔离与资源开销；真实资料大规模评测待补。
4. **接入与知识管理补齐**：批量失败独立处理已实现；已补手动知识和 FAQ 的编辑/索引/引用闭环；网页导入及 OCR 仍待完成。

每轮以“上游依据 → 本地实现 → 自动化/实际链路验收 → 剩余差异”交付。评测应包含通用知识库资料，不能只用科研问题。当前合成测试通过不代表真实文档准确率，也不能作为全部迁移完成的依据。

最新交付：`docs/releases/authored-20260909.md`。后续补 OCR 或 FAQ 相似问法/批量导入；网页导入与高级分块策略仍待明确输入类型和效果评测。
