# 云端语音输入

本批次在本地接入硅基流动 `/v1/audio/transcriptions`，替换浏览器
`SpeechRecognition`。尚未推送、构建镜像或发布线上。

## 模型和交互

- 主用：`Qwen/Qwen3-ASR-1.7B`；兜底：`XingChenAGI/XingChenASR-V3.2-Ultra`。
- 点击麦克风录音，再次点击结束；最长 60 秒，随后转写并追加到当前草稿，编辑后发送。
  转写本身不会发送聊天消息、启动 Agent 或写入记忆。
- 等待授权、录音和转写都可以取消。失败录音暂存在当前页面内存，支持重试；
  刷新、切换会话/项目/账号、取消、关闭提示或发送消息会清理它。
- 转写期间可继续编辑草稿，禁止发送；文本追加到最新草稿。旧请求晚到不会写入新会话。
- “模型与能力 → 语音模型”展示主备模型及启用状态。配置按账号缓存 5 分钟，
  只在打开该页签时获取，不调用模型、不增加聊天页的初始加载请求。

这是录完后识别，不是真正的流式 ASR。没有添加接口未声明支持的语言、热词、
prompt 参数，也不使用大模型自动改写识别结果。

## 请求边界

浏览器用 `MediaRecorder` 录音，`OfflineAudioContext` 解码和重采样为
16 kHz、单声道、16 bit PCM WAV。同源 `POST /api/audio/transcriptions`
使用登录 cookie 转发到后端 `POST /api/v1/audio/transcriptions`。
这两个内部接口接收 `audio/wav` 原始字节；后端按照供应商规范，以
`multipart/form-data` 发送 `file` 和服务器选择的 `model`。

两层接口都限制实际读取大小，不能靠伪造 Content-Length 绕过 2 MiB 限制。
后端校验 WAV 参数、真实帧数和 0.25–60 秒时长。上传读取上限 15 秒，认证后释放
数据库连接，不占着连接等待模型。不安装本地 ASR/FFmpeg，不保存音频文件。

## 故障和用量

- 网络错误、超时、404、408、429、5xx、畸形响应最多切换一次兜底，没有 SDK 隐式重试。
- 明确的 400/401/402/403/413/422 等错误不切换；空文本作为无语音处理。
- 两个模型共用同一供应商，不能覆盖供应商整体中断、Key 失效或账号欠费。
- Redis 提供跨进程的账号锁，每账号同时一份转写；释放时核对 token，110 秒自动过期。
- 默认每账号每天 1,800 秒，UTC 零点切换。每次调用前按录音时长向上取整预留；
  失败或取消不退款，兜底额外计入一次。这是应用成本限制，不是供应商账单。
- Redis 故障时不绕过额度付费调用。Redis 仅存账号锁和秒数，没有录音或文本。
- 日志仅记录模型名、状态码、校验后的供应商 trace ID；不记录 Key、音频、文本或上游错误正文。
  浏览器取消不能保证供应商已开始的请求不计费。

## 配置和发布

配置于被 Git 忽略的 `backend/.env`，不复制到前端：

```dotenv
ASR_ENABLED=true
ASR_BASE_URL=https://api.siliconflow.cn/v1
ASR_API_KEY=<server-only-key>
ASR_MODEL=Qwen/Qwen3-ASR-1.7B
ASR_FALLBACK_MODEL=XingChenAGI/XingChenASR-V3.2-Ultra
ASR_TIMEOUT_SECONDS=25
ASR_DAILY_AUDIO_SECONDS=1800
```

单次调用时限支持 5–45 秒；兜底模型设空可关闭切换。Key 与聊天模型独立。
compose 已加载该环境文件，发布新版后生效，本功能无需迁移。
此前聊天参数批次的 `0044` 迁移仍需随整批发布执行。

## 验证和限制

- 两个模型均出现在账号模型列表，对同一段公开的约 2.43 秒中文样例返回正确文本。
  首次请求 Qwen 约 0.48 秒、XingChen 约 2.64 秒；这是单次观测，不是性能基准。
- 新后端服务使用独立临时 Redis 调用 Qwen 成功。并发租约、原子额度与账号分离
  使用临时 Redis 验证，不接触生产 Redis/数据库。
- 单元测试覆盖主备顺序、永久错误、无声结果、超限/损坏录音、鉴权、配额、取消、
  旧请求隔离和 WAV 编码。浏览器测试使用真实 Chromium 录音和解码器、合成音轨，
  供应商请求使用 mock，覆盖桌面和手机尺寸。
- 尚未在实体 iPhone/Safari 或用户真实麦克风上验收，也未验证科研术语准确率。
- 长录音上传、实时字幕、说话人区分、跨供应商兜底暂未实现。

本批次最终验证：后端 535 项通过（77 项需额外环境的测试跳过），前端 130 项通过，
8 项桌面/手机浏览器场景通过。覆盖率门槛与 TypeScript、ESLint、Ruff 检查通过；
ESLint 的既有提示和 Redis 类型存根提示不阻断检查。临时测试服务已关闭。
