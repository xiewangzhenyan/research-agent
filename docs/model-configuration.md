# 模型配置加载

聊天、记忆提取和模型管理共用 `useGenerationConfig`，按账号缓存生成模型
列表、默认值及可调参数。模型选择不再等待沙箱或重排服务的健康检查。

- `/api/v1/agent/generation-config` 需要登录，仅返回脱敏的部署策略。读取过程不加载
  模型、不调用供应商、不探测沙箱或重排服务；实际生成时仍按服务器最新策略校验。
- 同一浏览器窗口内，数据在 5 分钟内保持新鲜；页面切换和并发组件复用同一请求。
  进入工作区时预取，不阻塞项目或页面加载，切换页面不会取消尚未完成的预取。
- 超过 5 分钟后，再次使用配置或网络恢复会触发后台更新，已有列表继续显示。
  无需定时轮询，也不会因为切回浏览器标签而重复请求。
- “模型与能力”的“刷新状态”可立即刷新配置，结果同步到该窗口其他选择器。
  更新失败保留上次列表并提示重试；首次失败、未登录或权限拒绝时不展示缓存配置。
- 缓存只放在当前窗口内存中，退出、切换账号时清除并取消请求。浏览器刷新、关闭窗口
  或项目切换导致整页导航后，会重新获取。不会持久化到 localStorage，也不走 CDN 共享缓存。
- `/api/v1/agent/capabilities` 保持原有兼容契约。仅在查看知识模型或平台能力时调用，
  健康状态使用独立的 30 秒前端缓存；重排探测另有 30 秒服务端缓存。
  界面展示真实检测时间，不将生成配置的缓存时间当作运行健康保证。

验证覆盖并发请求复用、缓存过期后的后台更新、手动刷新合并、网络失败降级、账号切换、
退出时取消请求，以及桌面/手机中聊天 → 任务 → 记忆 → 模型页的实际导航请求次数。
新增后端接口测试验证登录要求、字段脱敏、策略更新与健康探测无关。

## 回答参数与会话恢复（本地实现，待发布）

- 温度与 Top P 按 `AI_MODEL_CONTROLS` 中的精确模型 ID 开放，不按模型名称猜测。
  两项只能显式设置其中之一；选择 Top P 时不发送默认温度。未声明的参数、越界数值、
  布尔值、非有限浮点数及未授权模型都会被拒绝。
- 输出上限默认 8000 Token，包括可见正文与推理 Token。运营配置
  `AI_MODEL_OUTPUT_LIMITS={"模型ID":16000}` 可调整该模型额度；应用允许范围为
  256–32000，最终仍应符合实际供应商限制。前端读取服务端提供的范围；不改线上 `.env`。
- Responses 传输实际使用 `temperature`、`top_p`、`max_output_tokens` 和 `reasoning`。
  PydanticAI 的 `max_tokens` 映射到 `max_output_tokens`；当前不开放 seed、频率/存在惩罚。
  本地 HTTP mock 测试检查最终请求体，没有调用收费模型。
- 参数在消息接收事务中写入 `conversations.generation_options`（迁移 `0044`），
  与会话消息一起恢复。仅保存用户覆盖项；省略 `generation` 或传 null 表示沿用，
  传 `{}` 表示恢复服务器默认。每条任务仍保存独立的有效配置快照。
- 浏览器草稿优先于后台历史刷新；切换会话时丢弃未发送的参数草稿，首次发送获得会话 ID
  保留选择。已有会话尚未恢复时不能提交默认参数覆盖原设置。
- 最终普通回答、严格知识库回答和协作撰写遵守用户输出额度。查询改写、规划、审校、
  记忆提取等辅助步骤使用各自固定上限，不将短回答设置误用于内部结构化结果。
  任务总 Token、工具调用次数和澄清轮数限制继续生效。
- 推理「默认」沿用服务器策略；未发送推理参数不等于关闭模型内部推理。
  旧回答未记录的输出额度显示「未记录」，不补造历史参数。

参数协议参考：[OpenAI Responses 官方接口](https://developers.openai.com/api/reference/resources/responses/methods/create/)。

## 云端语音模型

语音输入使用独立的硅基流动配置，主用 `Qwen/Qwen3-ASR-1.7B`，
兜底 `XingChenAGI/XingChenASR-V3.2-Ultra`。在“模型与能力 → 语音模型”查看；
密钥只保存在后端。录音、额度、错误处理与验证边界见 [云端语音输入](voice-transcription.md)。
