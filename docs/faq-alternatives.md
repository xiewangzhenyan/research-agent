# 常见问答的相似问法

在知识库中新建或编辑 FAQ，可为一条标准问题填写最多 5 条相似问法，每条最多
150 字。每行一种问法，共用标准答案；保存后自动去除重复问法并重新建立索引。
处理状态沿用资料列表中的等待、分块、向量生成、完成或失败；失败可重试。

各问法分别参与本地向量和关键词检索。长答案按相同边界分段，每段保留对应问法，
不会为了拼入所有问法而截断答案。相同答案片段在融合排序和重排后只保留最佳命中，
前后文扩展也避免重复加入其他问法的同一答案。候选深度仍由现有检索配置约束，
本功能不承诺提高所有数据集的召回率。

原文下载包含标准问题、全部相似问法和答案，引用仍指向原资料及其版本。
修改沿用账号权限、版本冲突检测和索引代次校验；历史回答保留原有引用快照。
删除相似问法会触发重新索引，旧问法不再作为额外检索入口。

现有 FAQ 不需要迁移或强制重新处理；没有相似问法时保持原内容哈希和分块行为。
相似问法会增加片段数，仍受每份资料及知识库已有配额限制；本轮不包含自动生成
相似问法或批量导入。
