# 会话权限与账号隔离

Research Agent 按当前登录账号校验会话访问。普通会话读写将无权访问和资源不存在
统一返回 404，避免通过会话 ID 探测其他账号的数据。需要登录的接口在未登录时
返回 401；修改演示标记等显式权限操作可能返回 403。

| 操作 | 所有者 | 只读分享账号 | 编辑分享账号 | 管理员查看其他账号 | 公开链接 |
| --- | --- | --- | --- | --- | --- |
| 查看对话正文 | 支持 | 支持 | 支持 | 支持 | 支持 |
| 查看消息与工具记录 | 支持 | 支持 | 支持 | 支持 | 仅正文 |
| 修改标题、追加用户消息 | 支持 | 禁止 | 支持 | 禁止 | 禁止 |
| 归档、删除会话 | 支持 | 禁止 | 禁止 | 禁止 | 禁止 |
| 修改知识库或文献范围 | 支持 | 禁止 | 禁止 | 禁止 | 禁止 |
| 发起 Agent 续聊 | 支持 | 禁止 | 禁止 | 禁止 | 禁止 |
| 发布为演示会话 | 需管理员身份和专用接口 | 禁止 | 禁止 | 专用管理接口 | 禁止 |

管理员查看通过受保护的管理接口或已验证的管理员身份授权。核心读取方法必须
显式传入 `user_id`；只有受保护的管理员调用可以显式使用 `None`。新增消息、
归档和删除拒绝缺失的用户身份。无所有者的历史会话不会自动变成公开数据。

## 消息与分享

- REST 追加消息只接受用户正文，不能伪造 `system` / `assistant` 角色、内部思考
  或模型调用元数据；回答和工具记录由服务端写入。
- Agent 在读取历史、保存用户输入和保存回答时传递账号身份。续聊只允许所有者，
  防止编辑分享账号借用会话所有者的知识范围触发检索或工具调用。
- 分享按“会话 ID + 接收账号”检查。撤销时同时匹配 URL 中的会话和分享记录；
  接收账号可以退出分享，所有者可以撤销分享。
- 公开链接仅提供只读正文，不返回账号 ID、知识范围、附件元数据、工具记录或内部思考。
  撤销后的链接返回 404。已经被接收方下载的内容无法通过撤销收回。
- 公开演示与普通分享是不同入口，普通会话更新不能修改演示标记。

## 验证

```bash
cd backend
uv run pytest tests/api/test_conversation_access.py tests/test_services_conversation.py tests/test_model_config.py -q
```

回归测试通过真实 HTTP 路由和服务层执行，仓储使用隔离的测试替身，不连接生产数据库。
覆盖跨账号读写、只读与编辑分享、无所有者记录、管理员查看、匿名请求、公开链接、
角色伪造、撤销分享，以及 Agent 输入/回答保存涉及的权限传递。

本文描述账号与会话权限，不代表已经实现项目级长期记忆隔离、通用并行多智能体
或完整沙箱隔离；这些能力需要单独设计与验收。
