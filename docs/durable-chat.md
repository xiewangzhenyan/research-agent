# 会话持续执行

部署本功能需要先升级数据库至
`0043_durable_chat`，再协调更新 API、任务 worker 和前端；不能只发布前端。

## 用户交互

- 消息由 `POST /api/v1/chat/turns` 接收，成功后会话、用户消息、回答占位、执行记录
  和记忆提取入队在同一事务保存。浏览器不拥有生成任务，关闭网页不会取消已接收请求。
- 重新进入时从数据库恢复历史、执行状态、澄清问题和结果。最近 50 条先显示，更早
  消息按 `(created_at, id)` 游标读取。历史保存与模型上下文大小是独立的。
- URL 指定的会话优先；同一浏览器用账号和项目限定的最后会话 ID 恢复位置，仅保存
  ID，不把对话内容存入浏览器持久缓存。其他设备可从会话列表打开已有记录。
- 移除独立“后台任务／执行记录”页面及导航入口；新请求统一在对话发送。点击回答旁的
  “执行详情与文件”在会话侧栏查看协作进度、代码输出、检索配置并下载文件，不跳转页面。
  详情仅在打开时读取，关闭侧栏停止详情读取，不取消服务器执行。
- 旧 `/tasks` 地址重定向到聊天；`/tasks?id=<执行 ID>` 转为 `/chat?run=<执行 ID>`，
  保留指定项目和语言。授权读取后恢复关联会话。未关联会话的早期记录仍可通过原链接
  查看结果、引用和文件，处理澄清及取消；不删除历史数据，也不自动迁移旧记录。
  详情按账号、项目、执行 ID 隔离，无权访问或会话不匹配时不显示内容。
- 执行模式由系统决定。工具权限与执行模式分开：用户可允许本会话使用隔离 Python，
  系统仍决定何时调用；服务端复核账号权限和节点能力。附件、结果文件沿用原有沙箱协议。

## 调度与恢复

每条消息独立对应 `AgentRun` 和稳定的 assistant message ID。提交 UUID 按账号去重，
同一标识与不同请求或项目组合返回冲突；网络重试不会新增重复消息。每个账号最多
5 个未结束请求。同一会话按提交顺序执行，等待澄清时后续消息排队；不同会话可独立执行。
候选调度和 worker 正式领取两处均检查前序请求。

已有 PostgreSQL advisory lock、attempt fence 和 LangGraph 检查点负责独占与恢复。
生成增量约每 350 ms 合并保存一次，避免逐 token 增加事件行。浏览器活动期间每
800 ms 读取运行快照，空闲 15 秒检查一次，后台标签页暂停轮询，重新聚焦时刷新。
最终回答、工具记录、引用及完成状态在同一带 fence 的事务内提交。

浏览器断开只停止展示；用户点击停止才请求取消。执行进程中断可由 worker 重新领取；
中断中的模型调用可能重做，不能承诺外部模型只调用一次。沿用每次 5 分钟执行、
最多 12 次领取、7 天有效期及最多 5 次澄清的上限。服务端、数据库及 worker 可用是
继续处理的前提，离线指浏览器离线，系统不会无限期执行。

## 路由、上下文与权限

普通问答走直接路径，不增加路由模型请求。当前自动协作仅适用于已选择知识库、
严格资料模式、无附件且未限定具体文档的复杂综合问题。候选关键词筛选后用结构化
路由判断是否需要规划、研究、撰写和审校；低置信度或路由失败回退直接处理。
协作最多修订一次，每次检索最多 5 个核心片段，沿用原有引用校验。

当前模型输入取本条之前最多 30 条消息，并以完整消息为单位限制到 24,000 字符；
未完成回答不作为已知结论。项目记忆沿用用户开关与账号/项目范围，严格知识问答不注入
长期记忆。所有历史仍保留，可翻页查看；这里没有新增长期对话的无损自动摘要保证。
普通附件合计最多 20 MiB、解析文本最多 60,000 字符；计算附件沿用 5 个/5 MiB 的限制。

提交、状态读取、恢复执行、工具调用、知识引用和产物读取均保留相应权限检查。
引用原文只存在权限控制的引用存储，消息工具记录保留引用指针。

## 首屏加载

默认项目在身份确定后直接建立范围，不等待项目列表。指定项目用独立单项目接口验证，
验证前不挂载会触发私有数据请求的内容区；导航框架可先显示。项目列表在后台加载，
失败可从项目切换器重试。认证入口共享一次 `/auth/me` 请求；生成模型继续复用
账号内存缓存。开发服务器的按需编译耗时不能作为线上加载性能指标。

## 验证

`tests/test_durable_chat.py` 覆盖原子提交、幂等、真实 HTTP 历史恢复、分页、账号与
项目边界、同会话顺序及上下文、澄清恢复、执行进程重启、自动协作引用、项目记忆、
Python 权限和文件产物。测试仅允许使用以 `_review` 结尾的临时数据库。

`frontend/e2e/durable-chat.spec.ts` 在桌面与手机视口覆盖关闭标签页后重开、历史和
最终回答恢复、自动执行请求、慢项目列表不阻塞、指定项目请求范围。
`frontend/e2e/execution-details.spec.ts` 覆盖会话详情侧栏、代码输出、文件下载、关闭后
停止轮询但不取消执行、旧地址跳转与项目范围、早期记录引用及恢复、权限失效隐藏内容。
浏览器端使用模拟 API；真实任务执行由 PostgreSQL 集成测试单独验证。
