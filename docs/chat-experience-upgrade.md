# 聊天体验升级

## 第一批：本地实现，待集中发布

- 输入框采用中性边框、独立文本区和底部操作栏；移除文本框的绿色焦点轮廓，保留其他控件的键盘焦点提示。
- 删除常驻「工具权限」折叠块；附件和数据分析集中到「＋」菜单。数据分析仍需显式选择，服务端账号授权与严格知识库模式的限制继续执行。
- 提示消息改为顶部居中；语音错误留在输入区，区分权限拒绝、麦克风缺失、静音、识别服务网络失败和浏览器不支持。
- 麦克风 Permissions-Policy 改为同源可请求，实际使用仍由浏览器授权。中文界面使用 `zh-CN`，录音结束后由用户确认发送。停止、卸载、切换会话时清理识别实例，旧回调不能写入新会话。
- 中文输入法选词期间不触发回车发送；失败请求保留草稿；生成结束和附件上传结束不再自动抢占焦点。
- 助手回答改为开放正文；思考摘要默认折叠，支持展开动画及减少动态效果设置。
- 推理控制增加离散档位滑杆，继续遵守服务器提供的支持列表；手机端模型设置使用底部模态面板。
- Markdown 接入数学渲染，兼容美元和反斜杠分隔符；引用只在 Markdown 文本节点处理，保护代码与公式。流式未闭合的块级公式延后展示。
- 每条完成的回答可直接下载原始 Markdown，无需模型再次生成，也不要求启用 Python。
- 输入组件按账号、项目、会话区分生命周期；切换范围时重置临时工具选择与未发送的参数草稿，已发送参数在第二批中加入会话恢复。首次发送获得服务器会话 ID 时保留当前选择。

## 验证与边界

- 2026-09-13 本地验证：109 项前端单元测试及既定覆盖率门槛通过，TypeScript 检查通过，ESLint 无错误。桌面和手机的 32 个相关浏览器场景已验证，包括关闭后重开、澄清恢复、执行详情权限、模型缓存和首次发送时的参数保留。
- 浏览器回归使用模拟 API 和独立本地前端，未连接生产数据库。开发模式首次编译导致的页面等待超时经预热复验通过；原澄清测试的宽泛 Markdown 定位已限定到问题区域，避免与新增下载按钮重名。
- 回归样例包含两种 Drude 介电函数、行内数学、多行矩阵、流式片段、代码内引用标记、价格文本以及不可信公式链接。
- 语音自动测试采用模拟识别器，覆盖错误分支与会话卸载；浏览器测试检查实际响应头和错误展示。尚未通过真实麦克风、不同浏览器及不同网络完成端到端转写验证。
- 当前语音依赖浏览器识别服务，本批没有新增后端 ASR。权限策略修复不保证浏览器外部识别服务在所有网络可达。
- 本批没有修改线上模型能力配置。温度是否能调整仍取决于该模型在服务器上的显式策略；滑杆动画不改变上游模型能力。
- 有效的历史公式会获得新的显示效果；已经丢失运算符或反斜杠的历史原文不会被猜测修改。
- 第一批提供 Markdown 原文下载，第二批加入真实 Office 导出。

## 第二批：回答参数与文档交付（本地实现，待发布）

- 参数增加 Top P、输出 Token 额度、数值校验及采样互斥；实际 Responses 请求参数通过本地 HTTP mock 验证。精确模型能力、额度、会话恢复规则见 [模型配置](model-configuration.md)。
- 新增会话参数迁移 `0044_conversation_generation`；参数和下一条消息原子保存，重新打开会话恢复，历史刷新不会覆盖未发送修改。任务的有效配置快照与账号、项目、会话隔离保持独立。
- 已完成回答的导出菜单提供 Markdown、Word、Excel、PowerPoint。Office 根据服务端已保存回答生成，追加权限校验后的原文引用来源，无需模型再次回答。Markdown 继续保留页面正文原文。
- 新增受控 `create_document` 工具，普通持久对话可生成真实 Office/Markdown 文件，不依赖 Python 权限或沙箱。严格知识库问答使用无工具流程，仍可通过回答导出菜单下载文档。
- Word 支持标题、正文、列表、代码和表格；Excel 将 Markdown 表格拆为工作表，说明另放一页；PPT 根据章节分页生成文字幻灯片，表格内容以逐行文字呈现。Office 公式保留 LaTeX 文本，暂不转换为可编辑公式，不抓取图片，不添加宏或执行生成代码。
- Excel 将非数字内容明确存为字符串，防止公式注入；保留前导零和超过数字精度的标识。长文本先拆分，避免库静默截断。PPT 最多 60 页，超限或过长标题明确报错。
- 文档输入最多 10 万字符，最多 20 张表、1 万单元格，文件最多 2 MiB；并发模板渲染限为每进程 2 个。持久产物继续遵守每任务 20 MiB / 每账号 100 MiB 配额。
- 相同任务、相同文档内容得到稳定产物 ID；重复调用不重复占空间。写入仍检查 worker 执行权，事件只含元数据。回答内直接展示已保存文件卡片，点击才下载，不为每条历史回答新增产物列表请求。
- 下载经过登录、账号和项目校验；切换范围后忽略迟到下载。前端代理保留 Office 二进制、附件文件名及私有禁缓存响应头。

- 迁移 `0044` 已在临时数据库验证降级、升级和旧会话默认值回填。未对线上数据库执行迁移。
- Word/Excel/PPT 经对应库重新打开验证内容及确定性，检查前导零、公式注入、长文本、尺寸限制、LaTeX 符号保留；页面验证二进制下载和持久卡片。尚未通过真实 Microsoft Office/WPS 的完整排版验收。
